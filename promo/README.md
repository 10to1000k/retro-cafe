## 🛠 چطور دوباره بسازیم

پیش‌نیاز: Python 3 + `pip install pillow numpy arabic-reshaper python-bidi fonttools brotli imageio-ffmpeg`

```bash
cd promo
python make_music.py         # موسیقی پس‌زمینه (ساخته‌شده با کد، بدون نمونه‌ی بیرونی)
python make_audio.py         # میکس گویندگی + موسیقی (فایل‌های صدا در build/vo)
python render.py still 6.6   # پیش‌نمایش یک فریم (PNG)
python render.py video       # خروجی MP4 نهایی
```

- محتوای آیتم‌ها بالای `render.py` در `DISHES` و `VIBE` است.
- زمان‌بندی دقیق در `S_INTRO` / `S_FOOD` / `S_VIBE` / `S_REVEAL` / `S_OUTRO`.
- برای تغییر جمله‌های گویندگی، فایل‌های `build/vo/*.mp3` را جایگزین کنید و زمان‌های `VO_CUES` در `make_audio.py` را به‌روز کنید.

> نکته‌ی حقوقی: لوگوی اسنپ‌فود و نام تجاری آن متعلق به اسنپ‌فود است. قبل از انتشار عمومی، طرح را با اسنپ‌فود (یا واحد بازاریابیِ همکاری) هماهنگ کنید و از لوگوی رسمی خودشان استفاده کنید.
