# ☕ منوی دیجیتال کافه

منوی مخصوص گوشی که با اسکن QR کد باز می‌شه و روی GitHub Pages میزبانی می‌شه.

**آدرس منو:** `https://10to1000k.github.io/retro-cafe/`

---

## 📝 ویرایش منو (آیتم‌ها، قیمت‌ها، اسم کافه و...)

1. برو به آدرس مخزن در گیت‌هاب: `https://github.com/10to1000k/retro-cafe`
2. روی فایل **`index.html`** کلیک کن
3. بالای صفحه، آیکون **مداد ✏️** (Edit) رو بزن
4. دنبال بخش **«⚙️ داده‌های منو»** بگرد (با جستجوی مرورگر `Ctrl+F` عبارت «داده‌های منو» رو بزن)
5. تغییرات رو بده:
   - **قیمت:** فقط عدد، بدون جداکننده — مثلاً `95000`
   - **برچسب:** خالی `""` یعنی هیچ | `"special"` یعنی پیشنهاد ویژه | `"new"` یعنی جدید | `"soldout"` یعنی ناتمام
   - **آیتم جدید:** یک خط مثل بقیه اضافه کن
   - **دسته‌ی جدید:** یکی از بلوک‌های `{ ... }` رو کپی کن و اسم و آیتم‌هاش رو عوض کن
6. پایین صفحه، دکمه‌ی **Commit changes** رو بزن
7. حدود **۱ دقیقه** بعد، منوی آنلاین خودکار به‌روز می‌شه ✅

## 🖼 تعویض عکس پس‌زمینه یا عکس آیتم‌ها

1. توی مخزن، وارد پوشه‌ی **`images`** شو
2. **Add file → Upload files** و عکس جدید رو با **همون اسم قبلی** آپلود کن (مثلاً `background.jpg`)
3. Commit بزن — تمام! برای عکس هر آیتم هم آدرس عکس رو توی قسمت `imageUrl` همون آیتم بنویس

## 🖨 چاپ پوستر QR

فایل **`poster.html`** رو توی مرورگر باز کن و پرینت بگیر (A4 عمودی). اگه بعداً آدرس سایت عوض شد، کد QR جدید (`qr.png`) باید ساخته بشه.

## 📱 نصب منو روی گوشی (برای مشتری‌های همیشگی)

بار اول که منو باز می‌شه روی گوشی ذخیره (کش) می‌شه. از دفعه‌ی بعد حتی بدون اینترنت هم باز می‌شه. توی مرورگر گوشی هم می‌شه از منوی مرورگر گزینه‌ی **Add to Home Screen** رو زد تا آیکون منو روی صفحه‌ی گوشی بیاد.

## 🗂 ساختار فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | خود منو — همه‌ی آیتم‌ها و قیمت‌ها اینجان |
| `images/` | عکس پس‌زمینه و عکس آیتم‌ها |
| `images/items/` | عکس آیتم‌های منو (اسم هر فایل = اسم آیتم؛ برای تعویض، فایل جدید را با همون اسم جایگزین کن) |
| `fonts/` | فونت فارسی (کاری باهاش نداشته باش) |
| `icons/` | آیکون نصب روی گوشی |
| `manifest.json` و `sw.js` | ذخیره‌ی آفلاین و نصب روی گوشی |
| `poster.html` و `qr.png` | پوستر چاپی و کد QR |
