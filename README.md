# ☕ منوی دیجیتال RETRO CAFE

منوی مخصوص گوشی که با اسکن QR کد باز می‌شه و روی GitHub Pages میزبانی می‌شه.

**آدرس منو:** `https://10to1000k.github.io/retro-cafe/`

---

## 📱 مسیر مشتری (۲ لمس تا انتخاب)

1. **اسکن QR** ← صفحه‌ی خوش‌آمد (لوگو، ساعت کاری، «الان بازیم / بسته‌ایم»)
2. **لمس دسته** (نوشیدنی گرم، دمنوش، آیس کافی، خنک‌بنوش، شیک، غذا، قلیان) ← مستقیم می‌ره سرِ همون بخشِ منو

داخل صفحه‌ی منو:

| امکان | کارش |
|---|---|
| 🔍 جستجوی سریع (بالای صفحه، همیشه در دسترس) | مثلاً «لاته» یا «آیس» رو تایپ کن — فارسی/عربی و اعداد رو خودش یکسان می‌کنه |
| 🕐 وضعیت «الان بازیم / بسته‌ایم» + آمار کافه | توی صفحه‌ی خوش‌آمد و بالای منو، خودکار از ساعت گوشی حساب می‌شه |
| ⭐ پیشنهاد ویژه‌ی رترو | آیتم‌های با برچسب `special` این بالا هم نمایش داده می‌شن |
| 🕐 ساعت کاری و «الان بازیم» | خودکار از روی ساعت گوشی حساب می‌شه |
| 📞 تماس / 📍 مسیریابی / 📷 اینستاگرام | پایین صفحه، با یک لمس |
| ↑ دکمه‌ی بازگشت به بالا | وقتی تو صفحه اسکرول کردی ظاهر می‌شه |
| 📶 کار بدون اینترنت | بعد از اولین بازدید روی گوشی ذخیره می‌شه |
| 📲 نصب روی گوشی | از منوی مرورگر ← Add to Home Screen |

## 📝 ویرایش منو (آیتم‌ها، قیمت‌ها، اسم کافه و…)

1. برو به آدرس مخزن در گیت‌هاب: `https://github.com/10to1000k/retro-cafe`
2. روی فایل **`index.html`** کلیک کن
3. بالای صفحه، آیکون **مداد ✏️** (Edit) رو بزن
4. دنبال بخش **«⚙️ داده‌های منو»** بگرد (با جستجوی مرورگر `Ctrl+F` عبارت «داده‌های منو» رو بزن)
5. تغییرات رو بده (توضیح هر فیلد، پایین):

| فیلد | توضیح |
|---|---|
| `name` / `tagline` / `hours` | اسم کافه (لاتین، مثلاً `RETRO CAFE`)، شعار اختیاری (خالی = نمایش داده نمی‌شه)، ساعت کاری |
| `phone` / `address` / `instagram` | شماره تماس، آدرس، اینستاگرام — هر کدوم خالی (`""`) باشه، از منو حذف می‌شه |
| `openHour` / `closeHour` | ساعت کار به عدد ۲۴ ساعتی (مثلاً `10` و `22`) → برچسب «الان بازیم» درست می‌شه. اگه نمی‌خوای، هر دو رو `0` بذار |
| `heroImage` | عکس محیط کافه برای پس‌زمینه‌ی صفحه‌ی خوش‌آمد و سربرگ منو — الان روی `"images/hero.jpg"` ست شده. خالی بذاری، طرح خودکار میاد |
| `price` | قیمت. **ساده بنویس:** `115` = ۱۱۵٬۰۰۰ تومان. اگه کامل هم بنویسی (`115000`) درست نمایش داده می‌شه |
| `badge` | `""` هیچ | `"special"` پیشنهاد ویژه | `"new"` جدید | `"popular"` پرطرفدار | `"soldout"` ناموجود |
| `description` | توضیح و ترکیبات آیتم — نمی‌خوای؟ `""` بذار |
| `imageUrl` | آدرس عکس آیتم — خالی باشه آیکون دسته نشون داده می‌شه |
| آیتم جدید | یک خط مثل بقیه‌ی آیتم‌ها کپی/اضافه کن |
| دسته‌ی جدید | یکی از بلوک‌های `{ ... }` رو کپی کن و `id` (انگلیسی، بدون فاصله)، `icon` (ایموجی)، `name` و آیتم‌هاش رو عوض کن |

6. پایین صفحه، دکمه‌ی **Commit changes** رو بزن
7. حدود **۱ دقیقه** بعد، منوی آنلاین خودکار به‌روز می‌شه ✅

> 🧠 **نکته:** آیتم‌های «ناموجود» خودکار آخرِ دسته‌شون می‌رن پایین و کم‌رنگ نمایش داده می‌شن.

## 🖼 عکس‌ها

| کار | چطور |
|---|---|
| تعویض عکس یه آیتم | توی مخزن، پوشه‌ی `images/items` ← **Add file → Upload files** و عکس جدید رو با **همون اسم قبلی** آپلود کن |
| اضافه‌کردن عکس جدید | عکس رو آپلود کن و آدرسش رو توی `imageUrl` همون آیتم بنویس: `images/items/اسم-عکس.jpg` |
| عکس محیط کافه (پس‌زمینه) | عکس رو با نام `hero.jpg` توی پوشه‌ی **`images`** آپلود کن (یا هر اسم دیگه و توی `CAFE` بنویس: `heroImage: "images/اسم.jpg"`) |
| عکس قلیان‌ها | عکس تنباکوها با نام‌های `tobacco-*.jpg` توی `images/items` هستن؛ برای تعویض، فایل جدید رو با همون اسم جایگزین کن |

**نکته:** عکس‌های آیتم‌ها مربع‌اند (نسبت ۱:۱) و حدوداً ۵۰ کیلوبایت — همین سبکی رو حفظ کن تا منو روی موبایل و اینترنت ضعیف سریع باز شه.

## 🎨 لوگو

- **نشان گرد:** `assets/logo-mark.svg` — همان چیزی که در اسپلش، صفحه‌ی خوش‌آمد، سربرگ منو، فاوآیکون و آیکون‌های PWA استفاده می‌شه.
- **نشان + نوشته:** `assets/logo.svg` — برای چاپ، استوری و هدر سایت‌های دیگر.
- آیکون‌های `icons/` از همان نشان ساخته شده‌اند؛ اگر نشان را عوض کردید، این فایل‌ها را هم دوباره بسازید:
  `icons/icon-192.png`، `icons/icon-512.png`، `icons/icon-180.png` و `icons/icon-maskable-512.png` (نشان با حاشیه‌ی امن روی زمینه‌ی قرمز).

فایل **`poster.html`** رو توی مرورگر باز کن و دکمه‌ی «چاپ پوستر» رو بزن (A4 عمودی). اگه بعداً آدرس سایت عوض شد، کد QR جدید (`qr.png`) باید ساخته بشه.

## 🗂 ساختار فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | خود منو — همه‌ی متن‌ها، آیتم‌ها و قیمت‌ها اینجان |
| `images/` | عکس محیط کافه (`hero.jpg`) |
| `images/items/` | عکس آیتم‌های منو (اسم هر فایل = اسم آیتم؛ برای تعویض، فایل جدید رو با همون اسم جایگزین کن) |
| `fonts/` | فونت فارسی وزیرمتن + فونت لاتین لوگو (`AlfaSlabOne-Latin.woff2`) |
| `assets/` | فایل‌های برداری لوگو: `logo-mark.svg` (نشان گرد) و `logo.svg` (نشان + نوشته) |
| `icons/` | آیکون نصب روی گوشی |
| `manifest.json` و `sw.js` | نصب روی گوشی و باز شدن بدون اینترنت |
| `poster.html` و `qr.png` | پوستر چاپی و کد QR |

## 💡 استانداردهایی که رعایت شده

- طراحی **mobile-first** با در نظر گرفتن notch و safe-area گوشی‌های جدید
- اهداف لمسی بزرگ (۴۴ پیکسل به بالا) و متن خوانا با فونت فارسی وزیرمتن
- اعداد و قیمت‌ها با **عدد فارسی** و جداکننده‌ی هزارگان
- جستجوی **فارسی‌فهم** (ی/ي، ک/ك، آ/ا و اعداد فارسی و عربی یکسان دیده می‌شن)
- کنتراست رنگ مناسب، پشتیبانی از `prefers-reduced-motion` و ناوبری با دکمه‌ی برگشت گوشی
- کار **آفلاین** بعد از اولین بازدید (Service Worker) + نصب روی صفحه‌ی خانه (PWA)
