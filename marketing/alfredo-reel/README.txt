تغییرات نسخه ۳
--------------
- لوگوی جدید کافه در نشان گوشه، میان‌پرده‌ی لوگو و کارت پایانی
- هیچ تصویری از فضای کافه در ویدئو نیست (فقط غذا و متریال)
- قیمت به‌طور کامل حذف شد
- متن‌های فارسی بازنویسی و از نظر املا اصلاح شدند
- گویندگی با متن بازنویسی‌شده (بدون اعراب و با تلفظ ساده‌شده) دوباره ضبط شد
- سال‌ها با فونت فارسی و ارقام فارسی رندر می‌شوند (نه فونت لاتین)

ساخت مجدد
---------
cd src
pip install --break-system-packages pillow numpy arabic-reshaper python-bidi fonttools brotli imageio-ffmpeg
python3 audio_build.py     # vo.npy + timeline.json  (برش صحنه‌ها از صدا گرفته می‌شود)
python3 music.py           # music.wav
python3 audio_mix.py       # mix.wav
python3 render.py          # 1800 فریم در frames/
ffmpeg (طبق دستور پایین) → alfredo-reel.mp4

انکود:
$FF -framerate 30 -i frames/f%05d.jpg -i mix.wav \
  -vf "scale=1080:1920:out_color_matrix=bt709:out_range=tv,format=yuv420p" \
  -c:v libx264 -preset medium -crf 23 -profile:v high -level 4.0 -g 60 -bf 2 -threads 4 \
  -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv \
  -af "loudnorm=I=-14:TP=-1.5:LRA=11" -c:a aac -b:a 192k -ar 48000 \
  -shortest -movflags +faststart alfredo-reel.mp4
